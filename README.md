# Java DSA Practice

A collection of Java solutions to Data Structures and Algorithms (DSA) problems from LeetCode and other coding platforms.

This repository documents my ongoing journey to improve problem-solving skills, strengthen my understanding of core computer science concepts, and practise writing solutions in Java.

## 🎯 Goals

- Strengthen my understanding of data structures and algorithms.
- Improve logical thinking and problem-solving skills.
- Practise writing clear and maintainable Java code.
- Explore different approaches to common programming problems.
- Build consistency through regular coding practice.

## 🧠 Topics Covered

The repository covers a range of DSA topics, including:

| Topic | Areas of Practice |
|---|---|
| Arrays | Array traversal and manipulation |
| Strings | String processing and character operations |
| HashMap / HashSet | Hashing and efficient lookups |
| Linked Lists | Node traversal and linked-list operations |
| Stacks and Queues | Linear data structures |
| Trees and Binary Search Trees | Tree traversal and searching |
| Graphs | Graph-related problems and traversal |
| Sorting and Searching | Searching and sorting techniques |
| Recursion and Backtracking | Recursive problem-solving |

| Other Topics | Additional algorithmic challenges |

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) compatible with the project configuration.
- Maven.
- An IDE such as IntelliJ IDEA, Eclipse, or VS Code with Java support (optional).

### Clone the repository

```bash
git clone https://github.com/jmulla2447/jave_practice.git
cd jave_practice
```

### Compile the project

From the repository root, run:

```bash
mvn clean compile
```

### Run an individual solution

1. Open the project in your preferred Java IDE.
2. Navigate to the relevant Java source file.
3. Locate the class containing the `main` method, if present.
4. Run that class using the IDE.

Some online judge solutions use a platform-provided method signature rather than a standalone `main` method. Those solutions may need a test harness or the original platform's execution environment.
