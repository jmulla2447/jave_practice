## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) compatible with the project configuration.
- Maven.
- An IDE such as IntelliJ IDEA, Eclipse, or VS Code with Java support (optional).

### Clone the repository

```bash
git clone https://github.com/jmulla2447/jave_practice.git
cd jave_practice
```

### Compile the project

From the repository root, run:

```bash
mvn clean compile
```

### Run an individual solution

1. Open the project in your preferred Java IDE.
2. Navigate to the relevant Java source file.
3. Locate the class containing the `main` method, if present.
4. Run that class using the IDE.

Some online judge solutions use a platform-provided method signature rather than a standalone `main` method. Those solutions may need a test harness or the original platform's execution environment.
